# Growthbridge Brand UI Source of Truth

The supplied Growthbridge brand reference is the visual authority for the public website.

## Official core colors

- Growthbridge Navy: `#123B5D`
- Growthbridge Green: `#16A36A`
- Growthbridge Orange: `#F59E0B`

These are the only core brand colors. Derived shades in the design system are allowed only for accessibility, hover/active states, borders, and dark-mode contrast; they must not replace the core identity colors in primary branding.

## Typography

- Primary typeface: Montserrat
- Weights used: 400, 500, 600, 700, 800, 900

## Theme rules

- Public website: light by default; dark only when the visitor explicitly selects it.
- Admin Control Center: dark by default; light only when an administrator explicitly selects it.
- Public and admin theme preferences are independent.

## UI application

- Primary CTA: Growthbridge Green
- Secondary/brand action: Growthbridge Navy
- Accent/highlight: Growthbridge Orange
- Brand gradients may combine Navy → Green; Orange is used as a supporting accent.
- Public default page surface is white.
- Dark sections such as the footer remain intentionally dark and use the official navy family.
